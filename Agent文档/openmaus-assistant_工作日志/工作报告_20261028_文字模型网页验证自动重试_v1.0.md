# 文字模型网页验证自动重试 v1.0

日期：2026-10-28，Asia/Shanghai。项目：openmaus-assistant。用户看到 Saturn Cloud 返回“模型上游需要网页验证”后提出，再次发送请求应给上游账号调度器重新选号的机会。本轮沿既有本地开发范围实施，没有修改 Saturn Cloud 的账号池、路由、续签或部署。

## 结论

这类错误可以再次发送，但重发只会给上游调度器一次新的选号机会，不能保证一定换号。当前失败请求的本地记录为 `MODEL_UPSTREAM_WEB_VERIFICATION`、HTTP 503、`outputStarted:false`：上游没有返回文字、推理片段或工具调用，因此可以安全在传输层重试。

## 实现

- `adapters/reachai.mjs` 将 `MODEL_UPSTREAM_WEB_VERIFICATION` 纳入临时错误集合。
- 只在没有任何事件交给原生内核时重试；一旦产生文字、推理、工具调用或其他流事件，就停止重试，避免重复电脑/文件操作。
- 最多额外发送两次，退避 300 毫秒、900 毫秒，总窗口 90 秒；取消、鉴权/权限、输入错误和已开始输出的请求不自动重放。
- 达到上限后仍返回原来的可操作 503 提示，原始错误详情和凭证不会透出。

## 验证

- `node --experimental-strip-types --test tests/model-retry.test.mjs`：8/8 通过。
- `node --experimental-strip-types --test tests/reachai.test.mjs`：5/5 通过。
- 新增场景验证：前两次网页验证失败、第三次成功时只交付一份完成事件；网页验证发生在部分文字或工具调用之后时不重试；连续失败最多三次请求。
- 本轮未直接重放用户当前对话，也未修改账号池；重启本地服务后该规则对后续请求生效。
- [验证记录](../../evidence/model-web-verification-retry-20261028/verification.json)：Node 24 联合测试 23/23、类型检查通过，5217 页面返回 200，服务保持 live。

## 限制

Saturn 的账号选择和验证状态由上游控制。若所有账号都处于验证/退避状态，自动重试仍会返回 503；此时需要完成上游网页登录验证或切换模型。
