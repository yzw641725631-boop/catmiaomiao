## 变更与原因

此前 UI 以对话和简短工作摘要为主，普通对话的委派问题缺少可靠入口，模型成功回复可能被误看成工作完成，执行能力仅限任务目录文本。

- 新增 assistant-services 私有 MCP：接入明确授权文件夹（默认只读，可撤销）、真实 PDF/DOCX 提取、UTF-8/CSV 受控读写、公开网页检索/正文、偏好候选与确认、单次/每日提醒和真实定时 work thread。没有替代原生模型循环或委派。
- 私有临时凭证、实际 bot/thread 归属检查；目录/链接/旧哈希/归档/互斥检查继续有效；网页 DNS 与连接地址校验、逐次重定向校验、大小/超时限制。网页作为不可信来源。
- 偏好确认使用原生记忆 expectedHash，可拒绝/忘记；本地任务与提醒跨重启保存，稳定 sendId 去重，停机后补发一次。后台派工回执只表明已发起。
- 新增“能力”抽屉，工作列表→执行过程→产物/校验，小助理可打开关联工作；“已回复”和“已交付”由实际回执区分。普通对话派出的问题核对原生父任务后可回答。面板/字幕避让、长路径折行、复选框同行、窄窗口默认收起、Escape 和焦点处理保留。
- 工作详情从顶部概览打开；普通对话仍跟随最新回复，用户滚到底后可继续跟随工作步骤。旧闲置回复不长时间占据人物字幕。

主要代码：adapters/assistant-services.mjs、assistant-mcp.mjs、local-folders.mjs、document-reader.mjs、public-web.mjs、runtime.mjs、workspace-hook.mjs、server.mjs，及 app/src/ServicesDrawer.tsx、work.ts、App.tsx、assistant-services.css 等。上游 checkout 未改。
