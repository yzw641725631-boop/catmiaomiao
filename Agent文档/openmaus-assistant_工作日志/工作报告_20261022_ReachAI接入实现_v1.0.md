# 工作报告：ReachAI 接入实现 v1.0

版本：v1.0。日期：2026-10-22。项目：openmaus-assistant。

目标：执行用户“就按你说的来”和“继续”的指令，以 ReachAI/Saturn Cloud 提供 LLM、ASR、TTS，保留 OpenMausBot 的持久身份、记忆和原生委派。

本轮已实现 `adapters/reachai.mjs` 私有模型桥及原生协议、`realtime-asr.mjs` 同源 WebSocket 中转、运行时配置激活/回退、前台统一设置、PCM 重采样/实时字幕与 MP3 边下边播及打断。主助理、小助理使用实际内核和 coordinate_bots；平台侧没有第二套 Agent 调度。未改 ReachAI 代码、线上配置或固定上游 tracked 源码，没有借用其他项目凭证。

关键修复：bot 的角色/身份参数必须置于 settings，否则被创建接口忽略；内核 `/api/config` 不提供完整 instances 热更新，改为空闲时重启自有内核并复用身份/thread，失败回退，纯声音更改不重启模型。实时识别按 segment 去重并等待 reason:end；取消后的权限/握手/结果、错误帧和播放准备均正确回收。场景聚焦滚动导致顶栏上移亦已修正。

最终全量验证于 2026-10-21 完成：Node v24.19.0，TypeScript 通过、24 项测试通过/0 失败/0 跳过、Vite 构建通过。真实 OpenMausBot 内核对接合成 ReachAI 网关，实际派两名小助理并回传工具结果；涵盖模型切换持久化、目录脱敏、HTTP 200 业务错误、PCM/WS/播放取消等。证据：`projects/openmaus-assistant/evidence/app-checks-2026-10-21T15-46-57-169Z/report.json` 和 `test.log`。这些是隔离协议和控制器验证，不是线上模型、人声、真实麦克风或延迟实测。

浏览器验证了错误 Key、可用模型选择、声音页、实时统一引擎说明、焦点循环/Escape、前台聊天，以及 1366×768、1920×1080 布局。证据在 `evidence/reachai-ui-20261021/`，修正后的 1920 截图为 `scene-1920-fixed.png`。IAB 全屏尝试没有得到成功证据，原生浏览器全屏/125% 缩放继续待验收。
