# 自动恢复与防空转 v1.0

日期：2026-10-29，Asia/Shanghai。项目：openmaus-assistant。用户在闲鱼卡点诊断后要求添加自动重试并调整功能。使用 agent-doc-memory 沿项目入口、索引、卡点报告与开发准入恢复上下文，并登记本轮既有本地范围的补充确认。

## 实际变更

- `adapters/vision-retry.mjs`：将真实视觉上游 `VISION_UPSTREAM_ERROR` / HTTP 400 加入有限重试。与原临时视觉错误共用最多额外两次、1/2 秒退避，仅在 90 秒内发起补试。请求完整缓存，原工具链和用户消息不重放；本地输入校验 400、鉴权、取消和不完整响应保持不重试。
- `adapters/tool-recovery.mjs`：只在固定原生电脑工具 press_key 明确报告后台输入未送达、推荐 foreground，且该助理当前电脑许可为 full 时，补试一次前台输入。重试参数仍由原生工具 schema 校验；其他失败、授权拒绝与执行状态不确定的动作不自动重发。
- 原生工具结果内部 `ok:false` 或 `status:refused` 会映射为实际失败，避免把 `browser_consent_required` 包装成操作成功，不自动授权浏览器资料。
- 相同观察目标的语义状态重复三次提示、第四次暂停本轮。忽略快照 ID/元素 token 的更新；UIA 内容或截图变化视为进展，成功动作清空此前重复计数。停止信息保留在原生失败记录中，后续新任务使用新的检测会话。
- `adapters/workspace-hook.mjs`：固定哈希和唯一锚点校验后将恢复层接到原生 ChatToolSession 执行路径。上游 OpenMausBot checkout 未改，原生审批、schema、作用域、取消与进程回收保留。
- `adapters/native-capabilities.mjs`：补充助理操作说明，区分填写地址栏和真实跳转、区分拒绝和成功，并要求多步电脑任务交给独立工作。
