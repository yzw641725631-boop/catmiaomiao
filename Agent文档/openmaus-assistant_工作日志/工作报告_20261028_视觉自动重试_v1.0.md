# 视觉自动重试 v1.0

日期：2026-10-28，Asia/Shanghai。项目：openmaus-assistant。用户在获知“最多两次、仅视觉请求、避免重做电脑操作”的方案后回复“可以自动重试。”本轮沿既有本地开发范围实施，G1/G2/G4 补充确认已登记至 `projects/openmaus-assistant/docs/开发准入记录_v1.0.md`。大肥鱼人设方案未实施。

## 生效规则

- 初次视觉请求失败后，最多额外重试两次，等待 1000ms、2000ms；合计最多三次模型调用。仅在累计 90 秒窗口内发起额外尝试。
- 可重试错误仅为 `VISION_IMAGE_UPLOAD_FAILED` / HTTP 500，以及 `VISION_UPSTREAM_ERROR` / HTTP 502、503。
- 鉴权、权限、已明确的网页登录验证、输入/体积错误、超时、取消和不完整模型回复不自动重试。客户端关闭/停止时，等待中的补试立即取消，迟到回复也不继续交给内核。
- 同一个模型请求完整缓冲、校验后才返回原生内核。重试复用完全相同的消息、图片、工具历史，不新增用户消息，不重建任务，不重放此前已执行的工具。
- 账号依旧由美国网关正常选择。当前部分账号错误被网关统一包装为上传 500，本地无法确认底层具体原因，因此不能承诺补试一定换号、一定成功或已经修复账号。没有修改账号池、线上部署或重启续签执行端。
- 已结束的失败任务不自动重放；用户点一次原任务“重试”后，后续视觉调用采用新规则。
