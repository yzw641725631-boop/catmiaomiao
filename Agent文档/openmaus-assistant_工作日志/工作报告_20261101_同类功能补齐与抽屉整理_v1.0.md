# 工作报告：同类功能补齐与抽屉整理 v1.0

日期：2026-11-01（Asia/Shanghai）。项目：openmaus-assistant。接[整改第 1–3 步](工作报告_20261031_整改第1-3步_v1.0.md)。用户要求：去 GitHub 找 Grok Bot、Muse 这类助理有、我们没有的功能并加上，同时把上一轮复查列出的问题都改掉。

## 结果

1. 调研：对照 Grok Bot 官方文档、Muse 官方发布、OpenMausBot 上游 v0.1.121–v0.1.135、OpenClaw、Hermes Agent，按代码核对列出 16 项缺口，见 [feature-gaps.md](../../evidence/round2-20261101/feature-gaps.md)。其中 7 项上游服务端已经实现，只是我们没接出来。
2. 新增 7 项功能，都不需要外部账号：
   - **搜索历史对话**：记录卡上有搜索按钮，点结果直接跳到那条消息。
   - **回复某条消息与表情回应**：表情回应会作为反馈交给助理。
   - **对话里附带文档**：PDF、Word、文本、Markdown 等，单个不超过 10MB。主助理用新增的 attachment_read 工具读取，只能读对话附件目录里系统生成的文件名。
   - **通知中心**：顶栏铃铛显示未读数，可标记已读、全部已读。系统通知默认关闭，你打开后才会请求浏览器权限。
   - **特殊卡片**：表格和图表卡片会显示出来，不再被丢掉。密钥卡和登录卡也会显示；密钥只发送一次，存在本机服务端，不进页面状态、日志或网址。
   - **今天**：一页看需要你处理的、进行中的、今天的提醒和最近结果。另有早间简报，默认关闭，可设时间。
   - **主助理说话风格**：默认、简洁、温和、详细四档，可再补一句，对新回复生效。
3. 抽屉页改成首页风格：助理设置、能力与日常、技能与工具、我的助理、系统状态、工作明细都改为离屏幕边缘 20px 的浮动圆角卡片，标题、标签页、字号统一，人物不再被整块挡住。技能与工具底部被截掉的保存按钮已修好。
4. 代码整理：
   - 11 个组件和 5 个适配层文件重新排版。逐个编译比对，前后产物一致，最长一行从 3,028 字符降到 119。
   - 抽屉改为打开时才加载，主包从 569KB 降到 496KB。
   - 构建时把 dist 里不再引用的旧包移到 归档，不再堆在 dist 里。
   - evidence 里 23 个一次性脚本移到 `evidence/_archived-scripts-20261031/`，并附说明；33 个可复用的检查脚本保留。

## 注意

- **密钥卡和登录卡的来源**：主助理和小助理目前没有主动发这两种卡的工具，只有上游自己发出时才会出现。这样做是为了不改动现有小助理已保存的工具范围。
- **未汉化的文字**：上游有些说明是英文，界面里能映射的已换成中文。“今天”里“在等你：”后面那段仍是英文原文，例如 Fish Audio API key。
- **表情显示**：虚拟机没有表情字体，截图里表情显示为方框。Windows 上应正常，请顺便看一下。
- **发出的文件没有下载链接**：v0.1.121 不提供文档附件的回传，所以发出的文件只显示名字。
