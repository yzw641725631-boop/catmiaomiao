## 固定架构与当前能力

OpenMausBot 固定 v0.1.121 / 97a4a1cab96ab3d07b0c7dac275f69afc6e7a8dc，upstream/OpenMausBot 保持干净。核心 Apache-2.0，enterprise 独立许可。只有这一套 Agent/线程/协调/审批/记忆内核；React 前台通过同源 REST/SSE。Windows Node 私有 IPC 与固定哈希加载适配挂接文件工具、技能审核、原生例行/目标，未写入上游源码。最新 Node 24.22.1，pnpm 10.33.0；不要使用旧 PATH Node 22。

主助理独立陪伴/工作线程，动态成员来自原生 create_bot、持久登记与精确 Chief/同组/工具范围验证。左下只显示最近两名，团队页列全员；日常实例原 Chief 7e60e8a5-b4ad-4d80-ad17-a7d97e8f740b、chat 5ac4c945-ac16-4dfb-8d3e-70a1115c8a7d 与检索/文档/生活三位助理保持。

Skills 提议使用原生 skill_manage，审核显示完整内容、来源与 SHA，确认后启用。相关任务通过 assistant_skill_read 读取自己的技能/已审 references。MCP 使用原生导入、握手测试、启停、OAuth 与逐助理选择；新工具注册不等于所有成员已经可用。

专用浏览器沿用原生 Chrome、独立 profile 与真实 SSE 帧；可导航、观看、键鼠/输入法、接管/交还。browser 专用模式的 computer 必须设 browser，off 会关闭原生浏览器。Windows 使用固定 Cua Driver/SDK 0.28.2 和真实租约；实际驱动、工具目录、get_screen_size 通过，私人桌面观察/输入未自动验收。原来关闭的桌面权限保持关闭。

本轮受限自带目录读写/文档生成、公开检索和读取已授权目录等常规工具免逐步确认，外部写入/发送、私人电脑、技能审核等保持原生确认；旧审批不自动补批。主对话仅通过 assistant_start_work 新开工作，阻塞协调保留给独立工作。文件按工作目录和原生派工祖先绑定；路径、链接/硬链接、大小、归属与 hash 防护保留。UTF-8/CSV 可读写，覆盖前归档；PDF/DOCX 提取正文。docx 9.13.0、ExcelJS 4.4.0 创建新的 DOCX/XLSX，保存后重开校验，表格仅字面量；成果账本核对下载字节。实际回复、作者、文件优先展示，工具过程折叠。不提供任意终端、文件删除、扫描 OCR、用户项目测试执行，也不因模型声称完成而制造成功凭证。

公开搜索/正文读取沿用安全 HTTP 工具，来源是不可信资料。偏好建议经确认进入原生记忆，有 hash 冲突与撤销。旧提醒继续持久运行，新例行工作使用原生 routines，先关闭创建、登记归属再启用；独立运行目录/线程、暂停/恢复/立即运行/停止有回执，不复制旧提醒给第二个调度器。
