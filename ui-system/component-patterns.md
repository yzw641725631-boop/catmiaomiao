| ID / 名称 | 构成与用途 | 变体与状态 | 数据、权限和交互规则 |
|---|---|---|---|
| C01 人物场景 | 背景、人物、阴影、字幕；保持视线和陪伴感 | 静态/待机/可选口型；idle/listening/thinking/speaking/attention/offline | AvatarDriver 状态；只在真实录音时倾听，真实音频播放时 speaking；无资产时清晰回退，不换人物 |
| C02 对话与工作时间线 | 标题、聊天/全部工作筛选、持久条目、时间、来源、展开区、新消息提示 | 收起/标准/详情；loading/empty/offline/error | message/thread 稳定ID；阅读历史保留锚点；每条工作显示来源小助理，长代码只在展开区 |
| C03 小助理状态行 | 图标、名称、一行任务、状态、展开/停止入口 | 空闲/排队/执行/等你/完成/失败/已停止 | 原生 bot/task；最多显示两行主要任务，多项折叠到“查看工作”；没有百分比来源就不用假进度 |
| C04 输入与语音栏 | 多行文本、麦克风、发送、停止播报、录音状态 | text/recording/transcribing；sending/disabled/permission-denied/error | Enter 发送，Shift+Enter 换行，输入法组合期间不发送；草稿保留；发送回执区分 queued/accepted；录音结束只提交一次 |
| C05 修改和验证卡 | 文件概览、状态、差异展开、命令与结果引用 | diff-available/list-only/unavailable；test-not-run/running/pass/fail/stopped/unverified | 只读实际工作凭证；无快照不显示行数，无退出结果不显示“测试通过”；文件链接经服务端授权 |
| C06 审批卡 | 原因、实际动作范围、允许/拒绝/回答、等待状态 | open/submitting/resolved/expired/conflict | 原生 requestId+threadId；按钮禁用直到回执；过期后不能用旧卡批准新动作；不藏在自动消失 toast |
| C07 记忆与设置抽屉 | 模型/语音就绪、身份偏好、记忆编辑、版本冲突、日志 | loading/empty/editing/saving/saved/conflict/error | 原生记忆与 expectedHash；确认候选与执行例行任务分别操作；没有权限则解释只读 |
| C08 纯净视图按钮 | 可见的进入/退出入口、任务数量/待处理提醒 | default/pure/attention | 隐藏一般记录和小助理行；输入/退出仍可触达，重要待批准事件显示短提示；不等于停止任务 |
| C09 工作现场 | 原生独立浏览器帧/桌面帧、当前位置、接管/交还、停止 | preparing/ready/viewing/human-control/disconnected/error | 使用真实 SSE 帧与原生控制租约；坐标按画面比例映射，支持输入法；断线冻结最后一帧并提示，关闭查看不伪称任务已停止 |
| C10 技能与应用 | 纸色列表→详情/原文→操作回执；技能、MCP、邮箱日历、分配本领 | loading/empty/draft/disabled/unverified/connected/error | 技能审核核对原生内容哈希；账号保存不等于测试通过；MCP 测试不等于账户登录；工具按助理分配，凭据仅本地输入 |

2026-10-23 C05 扩展：DOCX 为实际文字阅读页，XLSX 为带表头、局部滚动的数据表；下载来自账本哈希核对的原文件。目标文件用“文件快照”，不虚构新生成回执。普通审批回答显示“已允许这次操作/已拒绝”，不向用户露出裸 `allow`；已处理过程默认折叠。

使用边界：主要动作只在所属卡/栏出现，不做多个不一致的“停止”。审批、发送和记忆写入的 loading/disabled 状态必须反馈当前处理对象。错误定位到所属组件，已有内容保留；成功以结果条目和可打开产物为主，避免庆祝动效遮挡人物。

示例：“编程助理 · 已修改 1 个文件”进入 C05；若只拿到 digest 文件名单，卡片写“已记录文件变化，差异待获取”，不能复制效果图的演示 `+1/-1`。用户说“以后简短一点”进入 C07 的偏好记录；它不弹出扩大工具权限的按钮。
