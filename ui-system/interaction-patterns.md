# 交互模式

2026-10-25 对话操作：语音识别后的指令与打字指令进入同一实际工具链；明确请求缺少信息时问具体缺项，已接通的可逆设置直接保存后简短确认。界面控件与对话修改共用服务端设置，收到 SSE 回执即更新，失败不显示已保存。名字、语速、减少动态、朗读打字回复、纯净视图、明确偏好及提醒管理见[本轮验收](../docs/对话式设置与语音操作验收_v1.0.md)。设定来源不会自行打开麦克风；权限、登录和凭证沿原生边界，不能把模型只收到转写解释为应用没有语音能力。

2026-10-25：沿用已有团队抽屉增加资料编辑，不增设空白设置页。点主对话标题的名字进入“我的助理”；主助理和小助理使用相同名字/笔入口及行内表单，保存中禁止重复提交，失败保留文字并显示错误。Escape 先取消名字编辑，再关闭抽屉；名称以持久接口回执为准并同步标题/作者/流式回复。改名不改变角色、任务或本领，不加二次审批。对话改名使用同一原生保存动作。见[验收与实际截图](../docs/助理改名与请求耗时验收_v1.0.md)。

2026-10-24 最新：按用户 Bot 截图落实三层交互，详见[降噪、权限与交互验收](../docs/降噪与权限交互验收_v1.0.md)和[本轮决策](voice-permissions-hierarchy-decision.md)。本段为当前规则，下方 10-23 及更早增量保留为历史；冲突处以本段为准。

人声由本地 Silero v5 的概率和至少320ms确认，停顿2000ms后才提交；噪声音量、未确认识别文字不能标记用户正在说话；已有连续输入和TTS行为保持。权限模式即时用于后续操作，原生全局仍ask；完全允许必须由用户在指定助理/资源保存，外部MCP与旧审批不扩权。模式可忙碌时单独保存，增减资源仍需空闲；失败回滚且不假成功。列表过滤、返回锚点、焦点/IME/断线草稿沿既有状态。

2026-10-23 最新规则：开启一次语音后，两秒停顿提交、接受后继续听；工作/团队/能力/工作现场保持收音，设置/断线暂停。按多个发送归属接收回复，用户正在说话时延后TTS，转为打字清空待播。TTS期间可手动点麦打断，非声学全双工。主对话通过独立工作回执恢复交流；自带受限常规工具免逐步确认，历史请求、外部写入/发送与私人电脑保留明确确认。图片失败保留原图和错误，不静默降级；见[当前验收](../docs/持续沟通与图片识别验收_v1.0.md)。

上一阶段，2026-10-23：语音单页面会话持有与转交、一次录音一次提交、45 秒等待恢复、消息状态定期同步、超时问题关闭、文件正文预览与精确链接下载，见 [ui-pattern-decision.md](ui-pattern-decision.md)。恢复等待不得重放文件操作或派工；QA 页面完成测试后关闭录音，避免与用户页面重复采集。

原生能力接入：浏览器/电脑接管使用原生租约，其他页面不能拿错误租约交还；断线保留最后画面并显示状态。账号保存、OAuth 完成、连接测试、分配给助理分别有结果，不能合并成一个假“已连接”。目标已处理的审批与工具默认折叠，真正待处理卡片保持可触达。旧版本启动权限冲突通过正常停止受影响的原生工作后迁移，不自动批准待处理工具或删除历史。

历史规则（已被上方修订替代），2026-10-22：能力抽屉与设置均暂停持续语音，关闭后恢复；转为打字终止。目录先明确接入、默认只读；候选偏好确认后入长期记忆；提醒明确单次/每日和提醒/后台工作，关闭服务时不运行。工作页打开实际主/子线程步骤，普通对话派出的补充问题也核验原父线程后回答。详见 [模式决策](ui-pattern-decision.md)。

日期：2026-10-21。PRD 事实入口为首版技术方案；实现/原型必须使用相同行为，并标明数据是真实或演示。

| ID / 场景 | 产品行为与界面表现 | 实现/原型要求 |
|---|---|---|
| I01 导航和焦点 | 展开详情/设置后可返回原处；Esc先关闭最高层可关闭浮层 | 恢复触发点焦点；设置/审批弹层有焦点约束；退出全屏沿用系统动作，不以Esc默认停止任务 |
| I02 发送与重试 | 发送显示处理中，回执区分已接受与排队；失败保留文字 | 输入法组合保护；稳定sendId；重复点击不发两次；队列取消有明确回执 |
| I03 阅读与新消息 | 历史阅读时不跳到底部；新消息累计在轻提示 | 保存消息ID和位置作为锚点；点提示才滚动；缺页/分支变化明确刷新 |
| I04 载入和空状态 | 场景可先出现，记录显示载入；无历史写“从这里开始对话” | 不放假消息/任务作默认真实数据；重连期间保留已显示内容 |
| I05 断线和失败 | 离线条提示连接情况；任务卡显示失败或等待重连 | 重新快照+去重；连接恢复本身不重复发送/播报；错误有所属范围 |
| I06 权限与禁用 | 请求麦克风时解释用途；拒绝后文字可用；审批有拒绝入口 | 权限未给不显示正在听；模型/语音未配置时控件有原因，不能静默无反应 |
| I07 两种停止 | “打断播报”停止当前声音；“停止任务”在对应工作卡 | UI文案不同；前者丢弃旧片段，后者绑定threadId；多任务停止逐项反馈，部分失败保留 |
| I08 成功/失败证据 | 结果以真实产物、差异和命令回执呈现 | 无证据=未验证；不能因 settled/模型口头结论变成绿色“通过” |
| I09 记忆保存冲突 | 保存成功提示当前版本；冲突保留双方内容 | 409不覆盖；用户选择合并后新hash重试；撤回使用journal并告知作用范围 |
| I10 习惯候选 | 显式偏好可确认；推测候选写“观察到”，可拒绝/暂停 | 不因确认偏好自动授权定时或文件操作；被拒候选不反复打扰 |
| I11 纯净视图 | 人物与对话优先；一般后台进度不打断 | 重要待处理卡用短提示可返回；成功工作安静累计；退出入口始终可达 |
| I12 降低动效 | 停止视差与待机循环，人物保留清晰状态 | 尊重prefers-reduced-motion；键盘focus清晰；状态文字不依赖动画 |

验证表单仅检查实际必填项：消息非空、语音/模型配置就绪、需要时的工作目录。错误紧邻字段或对应卡片，不使用大段技术栈说明替代“如何继续”。设置与记忆中的敏感字段不回显已保存密钥。
