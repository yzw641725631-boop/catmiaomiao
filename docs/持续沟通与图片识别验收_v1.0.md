## 美国视觉模型与真实失败

只读核对指定美国部署，实际目录中的模型是 deepseek-v4.1-flash-vision-exp；不是按语音猜测名称。ReachAI 当前可用实例目录没有该视觉项，文字/ASR/TTS 仍走原配置，图片经现有加密 SSH 链路访问美国本机网关。Whale 网关 Key 在服务器原地读取，没有导出到本地设置、浏览器、URL 或日志。没有调整线上部署、号池或路由。

真实结果：[单独识图](../evidence/interaction-vision-20261023/vision-live-2026-10-23T13-53-00-242Z.json) 18.078 秒通过；[带完整对话与 25 个工具](../evidence/interaction-vision-20261023/native-vision-2026-10-23T14-28-04-082Z.json) 18.209 秒通过；[真实页面截图](../evidence/interaction-vision-20261023/ui-vision-success-desktop.jpg)读出 ORBIT 84、120+30=150、红色正方形和蓝色圆形。使用的全是合成图，没有上传私人图片。

随后图片后台派工验收在工具调用前遇到 HTTP 500，实际返回 [Failed to upload inline file.](../evidence/interaction-vision-20261023/vision-response-diagnostic.json)。只读服务器日志在 14:27:21、14:34:54、14:36:17 UTC 对 file/upload_file 记录 Authorization Failed (invalid token) / code 40003。已证实部分被选中的上游账号令牌失效；不能据此断言全部账号失效，也不能把识图成功写成服务已稳定。没有绕过上游验证或反复重放。当前自然图片派工真实模型验收未通过。

视觉请求改成非流式时移除 stream_options，是兼容清理。前后成功与失败并存，根因应以账号失效日志为准，不能断言移除参数就修复 500。客户端将上传失败单独显示，保留图片和失败记录；诊断只记状态、错误码、时间与数量。美国账号恢复不在本轮只读接入修改范围内。

本地视觉传输仍依赖现有 Windows Python 和工作区 SSH 连接器，是本机集成，不是可直接搬走的安装包。旧图追问不能保证每轮再次获得原图；需要重新看细节时请重新附图，不能仅凭旧回复推断。
