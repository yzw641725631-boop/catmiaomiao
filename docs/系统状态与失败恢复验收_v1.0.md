# 系统状态与失败恢复验收 v1.0

日期：2026-10-25，Asia/Shanghai。范围：本机状态可见性、最近消息重试、后台监督进程恢复。G5 独立签字仍待完成，G7 未申请。

## 本轮实现

- 顶部连接标签打开“系统状态”抽屉，分别显示本机助理服务、LLM、语音、图片识别和后台例行调度。状态文案区分“正常”“需要检查”“未连接”；“已配置”不再被当作外部服务已经验收。
- `/companion/info` 增加最近模型/视觉请求的元数据状态，只保留成功/失败、时间、状态码和错误码，不记录提示词、图片、音频或密钥。
- 模型请求失败且消息仍保留时，输入区和状态抽屉提供“重试最近消息”。重试沿用原 sendId，避免网络超时后产生重复消息或重复工作。
- 后台启动入口对本项目自己的模型服务做有限退避重启，十分钟窗口最多重启三次；手动停止仍走原有 `quit` 和归档流程，不无限重放上游请求。
