# 个人助理能力与工作台扩展 v1.0

日期：2026-10-22（Asia/Shanghai）。用户认为功能与 UI 距 Muse 很远，并明确回复三项能力“都要做”、随后要求“继续”。本次将该回复视为文件、公开网页、偏好/提醒和工作查看的具体开发指令；沿用首版 G2/G4、人物与书房视觉。没有将它解释为读取任意私人目录、登录第三方服务或公开发布的授权。G5 为开发者自检，独立签字未取得；G7 未申请。

## 核对结论与范围

截至本日，[Muse 官方说明](https://ai.meta.com/muse/)包含独立浏览器、应用连接和持续后台工作。本项目此前只有对话、语音、有限委派和本次工作目录内的文本操作，不能宣称功能对等。本轮补齐三个明确模块及工作界面入口，没有接入完整登录浏览器、邮件/日历连接器、任意终端、自动购买、人物口型或系统常驻安装服务。

## 架构及执行

固定 OpenMausBot 内核继续负责真实模型循环、委派、记忆与逐次工具审批。新增 `assistant-services.mjs` 是能力服务，不是另一套 Agent 调度器。私有 MCP `assistant-mcp.mjs` 经随机本地端口和临时凭证调用；验证 Host、Origin 和实际 bot/thread。内核加载钩子按固定源码哈希注入，工作目录仍由原生 openedBy 祖先确定，上游 checkout 未改。

`start_work` 仅允许主助理从陪伴对话创建独立工作，让文件/调研从普通聊天进入有范围、证据和恢复入口的任务。模型提交稳定 request_key；本地派生 sendId，任务和输入关系持久化，重启继续原任务，避免另建重复任务。该回执表示接受，不表示完成。

### 本机文档

- 能力面板输入具体文件夹路径，默认只读；写入须明确勾选。没有自动接入桌面或磁盘。
- 文件夹授予、撤销和使用状态落盘；模型只能使用真实目录 ID，不能传绝对路径越界。每次模型工具操作仍经过内核审批。
- 读取 UTF-8 文本、CSV、PDF 文本、DOCX；PDF/DOCX 在限时子进程解析，单文件 10 MB、输出 5 万字符上限；扫描件/OCR、加密文档不支持。没有宣称进程是 OS 网络沙箱。
- 可写范围仅 UTF-8 文本；64 KB、路径/链接检查、精确旧哈希、覆盖前归档和互斥。PDF/DOCX 当前为读取，不写回这两种二进制格式。生成报告保存 Markdown/文本；原始文件默认保持不变。
- 模型读取的文档内容会进入所选模型上下文；能力提示和逐次读取卡明确说明。

### 公开网页

`web_search` 从公开搜索 RSS 返回真实 URL，`web_read` 实际请求、抽取正文、标注抓取时间和截断情况，模型报告应引用原链接。没有伪造资料、登录、表单操作或验证码绕过。DNS 全部地址检查、连接固定已校验 IP、每次重定向重新校验、禁止凭证和内网目标，响应/时间均有上限。网页作为不可信资料，不是执行指令。

这是一套公开检索/正文阅读工具，不能称为 Muse 的独立图形浏览器。动态登录网站和第三方应用待后续接入。

### 偏好与日常安排

- 模型可提出偏好候选，状态 pending；用户确认后，通过内核记忆 API 的 expectedHash 写入长期记忆。可拒绝、忘记；拒绝的同文候选不会重新变成待确认。不是后台监听和自动推断所有习惯。
- 用户也可在能力面板主动添加并确认偏好。原有完整记忆编辑、修订历史及撤销入口保留。
- 支持单次/每日提醒，明确北京时间。动作是本地提醒或发起真实 work thread；触发记录与 work ID 可追踪，暂停、恢复、取消保留历史。
- 本地服务运行、页面关闭时仍触发；服务退出或电脑关机期间不运行。重启后补发一次，每日错过多次合并为一次。没有安装开机启动/Windows 服务，不是云端 24 小时托管。
- 后台模型或文件操作仍可能等待逐次审批，界面不能显示已完成。定时派工失败保留原因并按 5 分钟退避，不频繁重复模型请求。

## UI 扩展

保留人物、背景、右侧记录、底部输入和持续语音的基本布局。新增“能力”抽屉（文件夹/网页/记忆/提醒），工作页快捷入口和单项过程页；小助理可点击打开关联工作。

对话页主要显示交流，工作过程页展示真实委派、读取、网页、保存、校验、返回和失败步骤；技术详情可展开。主/子线程通过实际 openedBy 归属，不混入其他任务。普通对话派出的旧小助理任务也可查看；其补充问题验证原生父任务后才能回答。

“已回复”与“已交付”分开：原生成功结束不代表用户目标完成；只有实际保存和校验回执的文件任务显示“已交付”。历史失败不被清除，主助理文字不能替代文件证据。待审批仍显式提示，独立工作可停止、失败后在原任务继续。

窗口较窄时记录默认收起，可按需打开；工作台可扩展。打开工作从顶部概览开始，普通对话跟随最新消息。正文与抽屉各自滚动，长路径折行、步骤详情折叠。调整样式加载顺序，避免旧设置样式覆盖新复选框与面板布局；缩短闲置字幕并限制工作面板高度，避免二者叠在一起。打开设置/能力暂停语音，关闭后恢复；“转为打字”终止持续倾听。
