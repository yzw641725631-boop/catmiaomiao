# 仓库使用说明

整理日期：2026-11-07。项目：openmaus-assistant。GitHub：<https://github.com/yzw641725631-boop/catmiaomiao>。

## 克隆与依赖

使用 Node.js 24 或更新版本、pnpm 10.33.0 和 Git。Windows 本机电脑控制需要额外准备项目原有固定版本驱动。

```powershell
git clone --recurse-submodules https://github.com/yzw641725631-boop/catmiaomiao.git
cd catmiaomiao
pnpm --dir upstream/OpenMausBot install --frozen-lockfile
pnpm --dir app install --frozen-lockfile
.\scripts\start.ps1
```

已经克隆的目录可运行 `git submodule update --init --recursive` 恢复上游。OpenMausBot 固定为 v0.1.121 / `97a4a1cab96ab3d07b0c7dac275f69afc6e7a8dc`，启动适配含源码哈希检查，请勿直接升级子模块。

启动脚本会先检查类型并构建前台，页面为 <http://127.0.0.1:5217/>。首次启动不含原开发机的模型连接和会话数据；在“设置 → 模型连接”中配置 Saturn Cloud 或 OpenAI 兼容接口。演示可使用 `.\scripts\start.ps1 -Fixture`。

`scripts/start.ps1` 会优先尝试原开发机的 Node 路径，再使用 PATH 中的 Node。`scripts/start-background.ps1` 仍含原开发机 Node 路径，在其他机器上应先调整该路径；前台启动不受此限制。服务正常关闭使用控制台 `quit`，后台使用 `scripts/stop-background.ps1`。

### 视觉与本机能力

现有美国视觉通道包含原开发环境的 Python 路径，并依赖原工作区的 `projects/sub2api/ops/galaxy-portal/remote.py` 运维连接模块及已授权远端服务。这些私人连接配置没有上传；单独克隆后需要自行配置视觉通道，不能直接继承原机器的权限或账户。主模型的文本兼容 API 配置入口位于本项目内。

原生浏览器、本机电脑、邮箱、日历和语音都需要对应依赖、用户账户或授权。依赖和权限状态按原项目实现检查；本次源码整理没有替用户开启权限。
