## 使用入口与实际行为

日常入口：http://127.0.0.1:5217/。已更新到本轮构建；原主助理、主对话、3 位小助理、192 条对话、长期记忆、模型设置和本领分配保持，见[前后核对](../evidence/voice-permissions-hierarchy-20261024/daily-after.json)。本轮合成工作均使用隔离目录，没有发进日常会话，没有批准历史请求。

- 对话：用户和助理气泡有独立填充与作者归属，日期分隔，历史过程折叠。正常后台任务使用短入口，不将等待人确认的任务算成正在执行。
- 动态：原来的大工作卡改为紧凑活动行；按全部、进行中、需要我、已完成筛选，显示真实作者、状态和时间。整行打开详情；返回保留筛选、滚动位置和键盘焦点。
- 详情：优先展示实际回复和交付文件。待确认请求直接可达；执行过程是独立一层，已处理操作默认折叠，参数和差异进一步展开查看。已知适配器附加说明不再当作用户正文显示，底层原记录保留。
- 权限：在“技能与工具 → 分配本领”选择助理，分别设置“这台电脑”与“专用浏览器”的“每次询问 / 完全允许”，再保存。新助理和旧配置缺省仍询问；本轮没有替用户开启完全允许。关闭资源后，关联完全允许失效；可以随时改回询问。
- 语音：复用浏览器降噪、回声消除与自动增益，新增本地 Silero VAD v5。人声概率及最短 320ms 人声成立后，才开始一句话；两秒停顿才提交。RMS 音量表和实时识别返回的零星文字都不能单独触发打断。未确认人声的实时音频不向识别服务发送原声；保留 600ms 预录，确认人声后补送。整段模式没有确认人声就不上传。

## 开源复用与权限边界

使用 `@ricky0123/vad-web` 0.0.31 / ISC、Silero VAD v5 / MIT 和锁定的 ONNX Runtime Web 1.30.0 / MIT。模型、worklet、WASM 和运行模块均由本地同源提供，未使用 CDN；SHA-256 在 `app/public/audio/vad/manifest.json`。第三方许可随本地资产保留在 `THIRD_PARTY_NOTICES.txt`。

原生 `approvalMode` 继续保持 ask。逐设备免询问只适用于已核对当前助理身份、原生 descriptor 对象和宿主标记的 computer/browser，不会因同名外部 MCP 扩大权限；每次调用重新读取保存的模式，改回询问影响后续操作。外部工具、技能审核和历史未处理请求保持原有门控。接管/交还仍由原生租约处理；模式保存不重置正在运行的助理，增减本领仍需空闲。没有修改固定上游源码。

## 仍需区分的未完成范围

合成样本不能代替用户当前耳机与房间的真人听感；本轮没有重新调用真实云 ASR/TTS 或改变现有模型。VAD 是人声判断，不是保证消除所有噪声；电视人声也可能被判断为人声。连续语音保持一次开启、自动续听到转为打字；TTS 播放仍暂停采集，尚非声学全双工。

外观已落实这次交互层次，用户审美验收待反馈。人物仍为已批准静态分层图，尚无真实口型或 Windows 安装包。此前 Whale2API 部分账号令牌失效导致图片上传 500 的问题本轮未处理，不能以新 UI 或 VAD 测试宣称修复。原生全屏、125% 物理缩放、长期稳定性和真实私人邮箱业务仍沿既有待验收范围。
