日期：2026-10-25（Asia/Shanghai）。用户明确要求：功能通过语音或对话完成，例如“你帮我改一下名字，叫小蕊就行了”，助理执行后确认，设置页作为辅助入口。沿用已有 G2/G4 本地开发授权，独立 G5 未终签，G7 未申请。

创建小助理、派工、目标、例行工作和技能继续复用现有工具，不另建代理循环。此表只表示本轮已接通的对话控制，不表示所有页面里的连接、账号、授权或浏览器全屏都已可免交互修改：模型连接/凭证、账号登录、文件夹和电脑权限、技能审阅等仍沿原生流程。声音 ID 支持用户提供的真实 ID 或恢复默认；没有声线推荐目录，不虚构“甜美女声”对应的 ID。

## 实现

`adapters/conversation-settings.mjs` 是界面和对话共用的设置源，保存至原来的 `companion-settings.json`。readReplies、reducedMotion、pureView 保存到 interaction；语速、音色保存到原来的 reachai.speed/voice，不另设优先级覆盖层。修改采用原生 `writeFileAtomic`，只合并明确字段；提交无效则整次不写入。已有浏览器本地偏好在尚未设置对应服务端字段时仍作初始值，后续明确保存以本地服务为准。

同源 `GET/POST /companion/settings/conversation` 与 `GET /companion/settings/events` 沿 Cookie/Origin 认证；SSE 只返回设置快照，不含凭证/服务地址。React 通过 revision 避免旧的历史同步覆盖新设置，偏好修改无需重启模型会话。设置页也调用同一接口；原模型连接页改变声音参数会发送快照通知，不留下会覆盖它的旧对话设置。

`assistant_app_settings`、`assistant_manage_preference`、`assistant_manage_reminder` 只允许当前主助理的主对话调用。常规免逐次审批只匹配本项目既有私有 MCP 描述符和服务凭证，不适用于外部同名工具；模型/密钥/电脑权限字段不能从这几个入口混入。既有工具审阅和外部写入规则保持。

原生用户最近问“听得到我的声音吗”时，模型错误解释为应用没有麦克风/语音通道。本轮从持续语音提交传入 `inputSource=voice`，保留到失败重试；模型上下文注明本句来自实际语音识别转写，用户文字本身仍按原样保存和显示。模型可回答已收到这句话，不用“模型只收到文字”否认应用的语音能力，也不据转写评价声学质量。文字输入标为 text。来源仅是描述信息，不改变消息幂等身份，兼容旧任务恢复和相同 sendId 重试。
